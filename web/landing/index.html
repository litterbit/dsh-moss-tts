三步开始

  1. 点上面的按钮，下载 MossTTS-win-x64-full.zip（159 MB，一次性）。
  2. 解压到任意目录（例如 D:\MossTTS），双击 moss_tts.exe。
  3. 浏览器会自动打开 http://127.0.0.1:8759/，输入文字、按 Ctrl+Enter 就能听到。

首次运行 Windows 可能弹"已保护你的电脑"（因为没有买代码签名证书）： 点「更多信息」→「仍要运行」即可。窗口不要关，关了服务就停了。

它能做什么

流式出声

不等整段算完：先出第一块（0.08 秒音频）就开始播，边算边放，浏览器里听不出拼接。

音色克隆

给一段 5～15 秒的 WAV，本地编码成几 KB 的 .mossclone，之后随时复现同一音色。

完全离线

下载完成后拔网线照样用。文字、音频、克隆样本都只在本机内存里。

零依赖

静态链接，只依赖 Windows 自带的 DLL。不需要 VC++ 运行库、Python、ONNX。

可嵌入

本地 HTTP 接口（/api/v1/*）+ C ABI 静态库，别的程序可以直接调。

同一套推理

网页、命令行、未来的 DeepSeek Harness 插件用的是同一个二进制、同一份权重。

接入自己的程序

命令行：

moss_tts.exe --text "你好，世界。" --voice Junhao --out hello.wav

本地接口（服务默认监听 127.0.0.1:8759）：

POST /api/v1/tts/stream → chunked s16le / 48000 Hz / 立体声； GET /api/v1/jobs/<id> 查统计；POST /api/v1/jobs/<id>/cancel 取消。

完整协议见仓库 doc/api.md；C 接口见 include/moss/tts.h。

环境要求

Windows 10 / 11 x64；支持 AVX2 的 CPU（2013 年后的 Intel / 2017 年后的 AMD 基本都有， 没有 AVX2 会自动降级到标量路径，速度约慢 2.6 倍）；内存 4 GB 起步（实际占用约 250 MB）；磁盘 200 MB。

模型来自 MOSS-TTS-Nano-100M（Apache-2.0），本项目做了 int8 4×4 量化重排、 fp16 编解码器与自有容器格式转换，改动说明见仓库 NOTICE。

本项目为独立实现，与模型作者无隶属关系。请只使用你有权使用的声音做克隆。
