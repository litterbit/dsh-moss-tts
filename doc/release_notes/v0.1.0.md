# MOSS-TTS CPU v0.1.0

第一个可以直接给非技术用户使用的版本：下载、解压、双击，浏览器里就能合成语音。
全部在**本机 CPU** 上跑，不联网、不上传文本，和未来的 DeepSeek Harness 插件共用同一个二进制。

## 亮点

- **流式出声**：首块 75~130 ms，边生成边播放（浏览器用 AudioWorklet 无缝排播）。
- **音色克隆**：给一段 5~15 秒 WAV，本地编码成几 KB 的 `.mossclone`，之后随时复现。
- **零依赖**：静态链接，只依赖 Windows 自带 DLL；不需要 VC++ 运行库、Python、ONNX。
- **一套推理**：`moss_tts.exe` 同时是 CLI、本地服务（`--serve`）和 SDK 的引擎；HTTP 与命令行输出的
  原始 PCM **逐字节相同**。

## 包内容

| 文件 | 说明 |
|---|---|
| `MossTTS-win-x64-full.zip`（~159 MB） | 程序 + 权重 + 18 个内置音色，解压即用 |
| `MossTTS-win-x64-lite.zip`（~1 MB） | 只有程序与网页，权重另取（插件/开发者） |
| `MossTTS-sdk.zip`（~1 MB） | `tts.h` + `moss_tts.lib` + API 文档 |

`sha256sums.txt` 是三个包的校验和。

## 开始

1. 解压到任意目录（例如 `D:\MossTTS`）。
2. 双击 `moss_tts.exe`（不带参数 = 起本地服务并自动打开 `http://127.0.0.1:8759/`）。
3. 输入文字，Ctrl+Enter。

首次运行 Windows 可能提示"已保护你的电脑"（未购买代码签名证书）：更多信息 → 仍要运行。

## 接口

`GET /api/v1/{health,info,voices}`、`POST /api/v1/tts/stream`（chunked s16le 48k 立体声）、
`POST /api/v1/tts/wav`、`POST /api/v1/voices/clone?name=`、`GET /api/v1/jobs/{id}`、
`POST /api/v1/jobs/{id}/cancel`。细节见 `doc/api.md`。

## 已知限制

- 只支持 Windows x64；没买代码签名，首次运行会有 SmartScreen 提示。
- 只监听 `127.0.0.1`，默认不允许网页跨源直连（门户页只负责下载/跳转）。
- 无 AVX2 的老 CPU 会自动降级到标量路径，约慢 2.6 倍。
- Safari / 移动端浏览器打不开本地试听台（loopback 的混合内容豁免在 Safari 上不成立）。
- 模型偶尔会在句尾低声"自言自语"；`/api/v1/tts/wav` 支持 `trim:true` 裁掉。
